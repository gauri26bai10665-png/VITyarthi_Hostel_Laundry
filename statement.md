# Project Statement

## Project Title

Hostel Laundry Management System

## Problem Statement

Hostel laundry services are often managed through manual communication, which can make it difficult for students to know about available laundry slots, manage their bookings, and track complaints.

The Hostel Laundry Management System provides a simple digital solution for organizing these activities. It allows students to view available laundry slots, book and cancel bookings, submit complaints, and check complaint status. Administrators can manage laundry slots, view registered students and bookings, and manage complaints.

The system is developed using Python, Tkinter, and SQLite.

## Scope of the Project

The project focuses on managing the basic activities involved in a hostel laundry service.

### Student Scope

Students can:

- Log in to the system.
- View available laundry slots.
- Book a laundry slot.
- View their bookings.
- Cancel a booking.
- Submit complaints.
- View complaint status.

### Administrator Scope

Administrators can:

- Log in to the system.
- View registered students.
- Add laundry slots.
- View all bookings.
- View all complaints.
- Update complaint status.

The current project is designed as a small-scale local application. Advanced features such as online payments, automated notifications, and cloud deployment are outside the current scope.

## Target Users

### Students

Students are the primary users of the system. They can use the application to manage their laundry bookings and complaints.

### Administrator

The administrator manages laundry slots and monitors student bookings and complaints.

## High-Level Features

### Student Features

- Student login
- View available laundry slots
- Laundry slot booking
- View booking history
- Booking cancellation
- Complaint submission
- Complaint status tracking

### Administrator Features

- Admin login
- View registered students
- Add laundry slots
- View all bookings
- View all complaints
- Update complaint status
